# 🐍 Snake Water Gun Game (Python)

A simple command-line game in Python based on the classic Snake-Water-Gun (like Rock-Paper-Scissors) concept.

## 🎮 Game Rules

 🐍 Snake drinks 💧 Water → Snake wins  
 💧 Water douses 🔫 Gun → Water wins  
 🔫 Gun kills 🐍 Snake → Gun wins  
 Same choices → It's a draw

snake = 1
water = -1
gun = 0

🛠️ How to Play
Run the script using Python.

Enter your choice:
s for Snake
w for Water
g for Gun

The computer randomly chooses one too.

The game declares the result instantly.
